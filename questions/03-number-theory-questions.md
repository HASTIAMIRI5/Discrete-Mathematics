# Questions: Number Theory and Divisibility

## Question 1
Find gcd(48, 18).

### Solution
48 = 18 × 2 + 12
18 = 12 × 1 + 6
12 = 6 × 2 + 0
So gcd(48, 18) = 6.

## Question 2
Find lcm(12, 18).

### Solution
gcd(12,18)=6
lcm(12,18) = (12×18)/6 = 36

## Question 3
Simplify 17 mod 5.

### Solution
17 = 5 × 3 + 2, so 17 ≡ 2 (mod 5).

## Question 4
Check whether 91 is prime.

### Solution
91 = 7 × 13, so it is not prime.

## Question 5
If a ≡ 3 (mod 7) and b ≡ 5 (mod 7), find a + b mod 7.

### Solution
3 + 5 = 8 ≡ 1 (mod 7)
