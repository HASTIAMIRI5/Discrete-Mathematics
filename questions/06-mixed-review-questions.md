# Questions: Mixed Review

## Question 1
Prove that the sum of the first n positive integers is n(n+1)/2.

### Solution
Use induction. The base case n=1 is true. Assume the formula holds for k. Then the sum to k+1 equals k(k+1)/2 + (k+1) = (k+1)(k+2)/2.

## Question 2
Find the gcd of 72 and 90.

### Solution
72 = 90 × 0 + 72
90 = 72 × 1 + 18
72 = 18 × 4 + 0
Therefore gcd = 18.

## Question 3
A bitstring of length 5 is formed with 0 and 1. How many possible strings are there?

### Solution
Each position has 2 choices, so 2^5 = 32 strings.

## Question 4
If f(x) = x^2 + 1 and g(x) = 2x - 3, find (g ∘ f)(x).

### Solution
(g ∘ f)(x) = g(f(x)) = 2(x^2 + 1) - 3 = 2x^2 - 1

## Question 5
Let A = {1,2,3} and B = {2,3,4}. Find A ∩ B and A ∪ B.

### Solution
A ∩ B = {2,3}
A ∪ B = {1,2,3,4}
