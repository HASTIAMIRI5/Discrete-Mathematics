# Questions: Sets and Functions

## Question 1
Let A = {1, 2, 3, 4, 5} and B = {3, 4, 5, 6, 7}. Find:
- A ∪ B
- A ∩ B
- A - B
- B - A

### Solution
- A ∪ B = {1, 2, 3, 4, 5, 6, 7}
- A ∩ B = {3, 4, 5}
- A - B = {1, 2}
- B - A = {6, 7}

## Question 2
If A = {a, b, c} and B = {1, 2}, find A × B.

### Solution
A × B = {(a,1), (a,2), (b,1), (b,2), (c,1), (c,2)}

## Question 3
Let f(x) = 2x + 3. Is f one-to-one? Is it onto the set of integers?

### Solution
It is one-to-one because if 2a + 3 = 2b + 3, then a = b. It is not onto the set of integers because it only produces odd numbers when x is integer, so not every integer is reached.

## Question 4
Find the power set of {1,2}.

### Solution
P({1,2}) = {∅, {1}, {2}, {1,2}}

## Question 5
If U = {1,2,3,4,5,6} and A = {2,4,6}, find A^c.

### Solution
A^c = {1,3,5}
