# Discrete Mathematics Study Repository

This repository is a structured study guide for discrete mathematics. It includes detailed explanations for core topics and practice questions with worked solutions.

## Course Overview

Discrete mathematics, also called finite mathematics, is the study of mathematical structures that are fundamentally discrete in nature. This course introduces foundational concepts that support technical fields, especially computer science. Topics include sets, combinatorics, number theory, functions, logic, recursions, relations, and graph theory. Students develop skills in counting, formulation, logical reasoning, problem-solving, and visualizing problems.

- **Program:** Bachelor of Science in Computer Science
- **Duration:** 9 weeks
- **Credits:** 3
- **Prerequisites:** None

### Learning Objectives and Outcomes

By the end of this course, students will be able to:

- Describe and apply basic structures of discrete mathematics.
- Identify mathematical arguments, apply logical thinking, and recognize faulty arguments.
- Find suitable solutions to real-world problems.
- Identify and apply different mathematical and logical notations.
- Demonstrate different methods of proof.
- Apply concepts of relations and number theory.

## How to Use This Repository

1. Start with a topic file to build foundational understanding.
2. Solve the matching question file.
3. Review the worked reasoning and explanations.
4. Revisit previous topics as needed to connect ideas.

Discrete mathematics is the language of computation, logic, structure, and proof. The goal of this repository is to make those ideas understandable and practical.
